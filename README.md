# Portfolio Maxence Bakana — Next.js + Tailwind

## Installation
```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Assets à placer dans `public/`
Le code réutilise les fichiers du portfolio actuel :
- CV_Maxence_Bakana.pdf
- Doc-Anaii.pdf
- windows-10.pdf
- windows-11.pdf
- windows-server-2025.pdf
- proxmox.pdf
- apache2.pdf
- docker.pdf
- glpi.pdf
- haproxy.pdf
- pfsense.pdf
- zabbix.pdf
- E6.pdf
- Lettre_Recommandation_Bakana.pdf (optionnel : à ajouter si souhaité)

## Fonctionnalités
- Design sombre et moderne
- Cartes interactives
- Modales détaillées à l'ouverture
- Recherche + filtres des documentations
- Navigation responsive
- Animations légères
- Liens vers les PDF
- Compatible clavier (Échap pour fermer une modale)
